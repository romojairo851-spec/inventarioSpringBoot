# ControlDeInventario2

Proyecto de control de inventario desarrollado con Spring Boot.

Este proyecto fue creado utilizando Spring Initializr como generador base del proyecto.

##  Descripción

Aplicación web que permite la gestión de usuarios mediante operaciones básicas (CRUD).

##  Tecnologías

- Java
- Spring Boot
- MySQL
- Maven
